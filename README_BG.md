# ProBG Продуктови стикери за OpenCart 3

OCMOD разширение за управление на многоезични продуктови стикери и показването им в продуктовите карти и продуктовите страници на OpenCart 3.

English documentation: [README.md](README.md)

## Версия

Текуща версия: **2.0**

## Инсталация

1. Качете `probg-stickers-2.0.ocmod.zip` през **Extensions → Installer**.
2. Обновете **Extensions → Modifications**.
3. Инсталирайте **Product Stickers** от **Extensions → Extensions → Modules**.
4. Адаптирайте активната тема, ако тя не използва стандартните продуктови шаблони на OpenCart. В стария [readme.txt](readme.txt) има пример за извеждане на стикерите.
